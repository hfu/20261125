## 構成（2024年）

1. 自己紹介（情報通信技術の背景、国土地理院、IPI ハノーファー、国連地理空間情報部、JICA）
2. 目的: 「Initiative に、どんな貢献ができるか。どんな利益が得られるか」
3. 参加型の導入: 付箋のように、地図にコメントを書き込めるページ（12時間後に消える）。「あなたの組織に、地理空間情報を公開する機能はあるか。はい / いいえ / 不明」の挙手。
4. 3つの話題: (1) UN Open GIS Initiative、(2) UN Smart Maps Group、(3) JICA 技術協力案件での Smart Maps のやり方。
5. Initiative: 2016年開始。平和維持活動の技術パートナーシップ。運用支援局と ICT 局が主催。目的は、国連の運用要件に合うオープンソース GIS による、拡張された空間データ基盤。
6. オープンソースが意味すること 6つ（アクセスしやすさ、カスタマイズ、協働、人材育成、透明性と信頼、持続可能性）。
7. **「開発途上国に届いているか? ——まだあまり成功していない。資源の不足のため。元のモデルは、平和維持ミッションと地域委員会を通すもの。JICA 案件には可能性がある」**（原文の趣旨）。
8. DWG の一覧、DWG7 の活動、Smart Maps の定義、vision と mission。
9. 最近試している技術: 生成AI、Portable Web。FOIL4G(誰でもデータを足せるオープンな地理空間ライブラリ)、DuckDB Wasm、PMTiles。
10. Smart Maps Portable（「弁当箱サーバー」）: Raspberry Pi 4B + UPS + SSD 2TB + GNSS アンテナ。外部電源なしで18時間。Wi-Fi 接続の実演（SSID と URL を画面に表示）。25台以上のクライアントを想定。
11. ホスティングの選択肢: オンプレミス、オブジェクトストレージ、既存のプラットフォーム（Source Cooperative、HDX、UNDP GeoHub など）、可搬サーバー、IPFS。
12. JICA 技術協力は、能力開発。**3層モデル**: 技術的能力、中核的能力（組織や個人の習慣と能力。計画、予算、要求）、環境（枠組み、標準、オープンデータ政策、国際協力）。「技術能力だけでなく、中核と環境を、もっと重視すべき」。
13. 価値は、戦略的な利用で生まれる（運用、状況認識、意思決定）。
14. 可用性の例: **NSDI プラットフォームが80%、ベースマップのサービスが98%**。「より単純なサービスを、より分散して作れる」。

## 気づいたこと（Claude の見方）

- **2年前に、すでに「開発途上国には、まだあまり届いていない」と、正直に話している。** 今年の「生き残る」「部活動的」という見方と、連続している。
- **3層モデル（特に中核的能力）は、「ドナー事業で引き受けたものの面倒を見る」現実を、あからさまに言わずに、尊重できる枠組み。** 「予算、要求」が入っている。今年の話で、静かに使える。
- **参加型の仕掛けがあった**（地図へのコメント、挙手）。今年の第1ブロック（実習）の前後に、小さく入れられる。
- **Wi-Fi に接続する実演を、すでに2年前に行っている**（SSID と URL を表示）。今回の実習の先例。
- 80% と 98% の可用性の数字は、原資料のまま。出典は未確認。
