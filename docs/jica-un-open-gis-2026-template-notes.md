# スライドテンプレートの方針メモ（Claude の案、2026-11-21）

スライド生成の前に決めること。ロゴは `dwg7/logo`（v0.6）を使う。書き換えてください。

## 1. ロゴ（`assets/logo/` に取得済み）

| 用途 | 使うファイル |
|---|---|
| タイトルスライド（白地） | `dwg7-primary-1200w.png`（2行: 文字とタグライン） |
| タイトルスライド（濃紺地） | `dwg7-primary-dark-1200w.png` |
| 本文スライドのフッター | `dwg7-wordmark-1200w.png`（タグラインなし。小さいとき用） |
| 濃紺地の本文スライド | `dwg7-wordmark-dark-1200w.png` |
| 1行のヘッダー | `dwg7-horizontal-1200w.png`、`dwg7-horizontal-dark-1200w.png` |

ロゴの決まり（`dwg7/logo` の README より）:

- 色を変えない。変えてよいのは、用意された別バージョンだけ。
- 伸ばさない、回さない、縁取りしない、効果を付けない。
- 別のフォントで描き直さない。
- 高さ48 px 未満では、タグラインなしのワードマークを使う。
- **国連のエンブレムは使わない。** dwg7 が国連 Open GIS Initiative の作業部会であることは、ロゴではなく**文章で**書く。
- ライセンス: リポジトリに CC0 の LICENSE があるが、README には「dwg7 の共同議長が決める」とある。講義での使用に支障はないと思うが、念のため。

## 2. 色

ロゴの色を基準にする。

| 役割 | 色 |
|---|---|
| ブルー（主色、ロゴの dwg） | #1E5AA0 |
| インク（濃い文字、タグライン） | #13233A |
| 濃紺地での明るいブルー | #6FA8E8 |
| 濃紺地での文字 | #E6EDF3 |

提案（ロゴにはない色）: 白地 #FFFFFF、薄い灰青の面 #EEF3F9、強調に使う1色（候補: 琥珀 #E8A33D。昨日までの案の差し色）。
☐ 強調色を使うか、ブルー1色で通すか。

## 3. フォント

ロゴの設計に合わせる。

- 見出し: **Sora**（ロゴは weight 500）
- コマンド、URL、コード: **IBM Plex Mono**（weight 400）
- 本文: Sora を想定。日本語は使わない（スライドは英語）。

注意:

- Sora と IBM Plex Mono は、**この Mac に入っていない**（確認済み）。講義に使う PC に、TTF/OTF を入れる必要がある（ライセンスは SIL Open Font License。Google Fonts から入手できる。ロゴのリポジトリには woff しかなく、PowerPoint には使えない）。
- PowerPoint はフォントを埋め込めないので、入っていない PC では代替フォントになる。**PDF を必ず用意する**（バックアップ）。
- ☐ 講義に使う PC は何か（Mac か Windows か、PowerPoint か Keynote か）。

## 4. レイアウトの型（テンプレートのマスター）

16:9（13.33 × 7.5 inch）。文字は少なく。

| 型 | 使う場所 |
|---|---|
| Title | 冒頭（ロゴは primary） |
| Section | 各ブロックの冒頭（濃紺地、時間を小さく） |
| Content | 見出し + 箇条書き（3〜5行まで） |
| Terminal | コマンドと出力（濃紺地、IBM Plex Mono、大きく）。第1ブロックの中心 |
| Screen | 画面や写真を大きく、キャプション1行 |
| Project | 各プロジェクト用。「必要 → 試したこと → 分かったこと → まだ分からないこと」 |
| Table | IPの表（スライド25の形を引き継ぐ） |
| Closing | 締めと References |

右下に、小さくワードマークとページ番号。

## 5. 生成の方法

- いまの生成元は `src/data.js` と `src/build.js`（pptxgenjs）。テーマと型を差し替える。
- 案: **マークダウンから、スライドを生成する**。`###` が1スライド（または1グループ）、箇条書きが本文、コードブロックが Terminal 型、`> 時間:` の行は発表者ノートへ、`> 確認（Claude）:` の行はスライドに出さない。そうすれば、機内で直したマークダウンが、そのままスライドに流れる。
- ☐ この方式（マークダウン → スライド）でよいか。それとも、`data.js` を直接書くか。
